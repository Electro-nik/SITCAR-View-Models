Інші та відкинуті моделі

Додаткові кандидати та відкинуті моделі. Якщо модель уже має реальний SITCAR-тест (наприклад Claude Fable 5), її результат може одночасно бути у верхній таблиці, а тут лишається пояснення рішення. Ціни наведено за 1M токенів без нашої податкової/комерційної націнки. Intelligence — Artificial Analysis Intelligence Index; вищий бал = сильніша модель.

Як тепер рахується вартість

Кожен напрямок SITCAR рахується за його власним фактичним API-запуском. Тобто SYS, STR, INN тощо більше не оцінюються через множення вартості ORG. Якщо для моделі є лише ORG — у розрахунку присутній лише ORG. Якщо є ORG + SYS + STR — складаються фактичні вартості саме цих трьох запусків.

Безплатна · фактичний output Сума фактичної вартості наявних модулів ORG + SYS + STR. Якщо протестована лише частина — біля суми показується покриття, наприклад 1/3 мод. · частково.
Повна · фактичний output Сума фактичних вартостей дев'яти напрямків ORG, SYS, STR, INN, TAL, CUL, ADA, REP, ARC плюс окремого фінального API-запиту FULL. За повного комплекту це 10 реальних API-запусків. Непротестовані запуски не вигадуються і не екстраполюються.
Безплатна · MAX Для кожного наявного Free-модуля береться його реальний input, але output підставляється рівним максимальному output моделі. Після цього модульні значення складаються.
Повна · MAX Такий самий MAX-розрахунок для всіх реально наявних запусків повної діагностики, включно з FULL, якщо є його HTML. Це верхній сценарій для вже протестованого набору, а не прогноз вартості відсутніх запусків.

Важливо для інтерпретації

  • У наступних напрямках вхід збільшується, бо до відповідей поточного розділу можуть додаватися результати попередніх напрямків, документи та метрики.
  • Тому коректніше використовувати реальну вартість кожного окремого модуля, а не множити ORG на кількість запитів.
  • Позначка частково означає, що для цієї моделі ще немає всіх необхідних тестів; показана сума — лише за реально наявні HTML-запуски.
  • PDF-файли з папки PDF_RESULTS показуються поруч з HTML як альтернативний формат результату, але сам PDF не додає окремої вартості — розрахунок виконується за HTML API-запуском.
  • У v15 result HTML працюють у read-only режимі: builder їх не переписує, а лише читає для метрик і формує index.html.
  • Колонка AA Intelligence показує актуальний Artificial Analysis Intelligence Index для наших протестованих моделей; вищий бал = сильніша модель.
  • FULL.html — це окремий фінальний API-запит, тому його фактичні токени, latency і вартість входять у Повну версію. FULL.pdf — лише альтернативний формат цього самого результату і окремої вартості не додає.
  • Окрема презентація / фінальний загальний API-запит не додається до ціни автоматично без реального HTML тестового файла. Якщо HTML з кодом FINAL / PRES / PRESENTATION з'явиться, скрипт підхопить його.
  • Сумарний час у назві моделі — сума latency усіх реально протестованих HTML-запусків повної діагностики: 9 напрямків + FULL, якщо він є.
